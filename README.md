# OPD Paperless · คลินิกผู้สูงอายุ โรงพยาบาลบ้านกรวด

เว็บแอปสำหรับคลินิกผู้สูงอายุ ใช้แทนกระดาษตั้งแต่ลงนัดจนผู้ป่วยกลับบ้าน
เป็น HTML/CSS/JavaScript ล้วน **ไม่ต้อง build ไม่ต้องติดตั้งอะไรเพิ่ม** ใช้งานได้แบบออฟไลน์ และติดตั้งลงมือถือ/แท็บเล็ตได้ (PWA)

## การทำงาน

| หน้า | ใช้ทำอะไร |
|---|---|
| **นัดหมาย & คิว** | พยาบาลประจำคลินิกลงนัดของเดือน พร้อมสิ่งที่ต้องทำก่อนพบแพทย์ (เจาะเลือด, ประเมินซ้ำ, X-ray, EKG) · ปฏิทินบอกจำนวนนัดแต่ละวัน · คิวเรียงตามเวลานัด · เปลี่ยนสถานะได้ |
| **ลงทะเบียน** | แสดงผู้ป่วยนัดวันนี้ กดชื่อแล้วออกคิวและส่งซักประวัติทันที · ผู้ป่วย walk-in/ส่งต่อกรอกเอง (ชื่อ สกุล อายุ HN) · ขอความยินยอม PDPA ครั้งแรก · พิมพ์บัตรคิว |
| **ซักประวัติ & ประเมิน** | สัญญาณชีพ (คำนวณ BMI, OSTA ให้) · ประวัติ · หน้าต่างประเมิน 2 เมนูบาร์: **1. ประเมินเบื้องต้น 13 ข้อ** และ **2. แบบประเมินละเอียด** ตามคู่มือคัดกรองและประเมินสุขภาพผู้สูงอายุ พ.ศ. 2564 (21 เครื่องมือ คิดคะแนนและแปลผลให้ แนะนำแบบประเมินถัดไป) |
| **แผนการดูแล** | สรุปสำหรับแพทย์ (คัดลอกได้) · ส่งต่อ/สุขศึกษาที่ระบบแนะนำตามผลประเมิน · นัดครั้งถัดไปพร้อมสิ่งที่ต้องเตรียม → สร้างนัดในหน้านัดหมายให้อัตโนมัติ |
| **ใบนัด** | ใบนัดสำหรับผู้ป่วย/ญาติ พิมพ์ได้ |
| **ค้นประวัติ** | ค้นด้วยชื่อหรือ HN · ตารางผลประเมิน 13 ด้านทุกครั้งที่มา · สัญญาณชีพย้อนหลัง |
| **รายงาน** | สรุปรายเดือน · จำนวนผู้เสี่ยงแต่ละด้าน · ส่งออก CSV ทุก visit ไปทำสถิติ |
| **ตั้งค่า** | ชื่อผู้บันทึก · สำรอง/นำเข้าข้อมูล · ระบบกลาง Google Sheets |

ทุกหน้าที่มีข้อมูลกด **ส่งออก CSV** (เปิดใน Excel ภาษาไทยไม่เพี้ยน) หรือ **พิมพ์ / PDF** เพื่อแนบเวชระเบียนในระบบของโรงพยาบาลได้ (แอปนี้ไม่ได้เชื่อมกับ HIS)

## เปิดใน VS Code

1. แตกไฟล์ zip → ใน VS Code เลือก **File › Open Folder…** แล้วเลือกโฟลเดอร์ `opd-paperless`
2. VS Code จะถามให้ติดตั้งส่วนขยายที่แนะนำ กด **Install** (Live Server)
3. คลิกขวาที่ `index.html` › **Open with Live Server** เบราว์เซอร์จะเปิด `http://127.0.0.1:5500` และรีเฟรชเองทุกครั้งที่บันทึกไฟล์

> ดับเบิลคลิก `index.html` ก็ใช้งานได้ แต่ฟีเจอร์ติดตั้งแอปและออฟไลน์จะทำงานเมื่อเปิดผ่าน Live Server หรือเว็บ HTTPS เท่านั้น

## โครงสร้างไฟล์

```
index.html            หน้าแอป (โหลดไฟล์ js ตามลำดับ)
css/style.css         สี ตัวอักษร และหน้าตาทั้งหมด (สีหลักอยู่ใน :root บนสุด)
js/store.js           เก็บข้อมูลในเครื่อง, วันที่ไทย, ส่งออก CSV, สำรองข้อมูล, sync Google Sheets
js/data.js            แบบประเมิน 13 ข้อ + แบบละเอียด 21 เครื่องมือ, เกณฑ์แปลผล, รายการส่งต่อ/สุขศึกษา
js/ui.js              ไอคอน หัวหน้า แถบขั้นตอน รายงานสำหรับพิมพ์
js/view-*.js          แต่ละหน้าจอ (appts, register, visit, plan+slip, patients, report, settings)
js/app.js             router (#/ชื่อหน้า) และการรับคลิก/การกรอก
sw.js                 service worker สำหรับออฟไลน์
apps-script/Code.gs   โค้ดระบบกลาง Google Sheets (ไม่บังคับ)
```

### แก้ไขที่พบบ่อย
- **เพิ่ม/แก้ข้อคำถาม หรือเกณฑ์แปลผล** → `js/data.js` (`App.DOMAINS`, `App.tools`, `App.judge`)
- **เพิ่มรายการส่งต่อ/สุขศึกษา** → `App.REFERRALS`, `App.EDUS` ใน `js/data.js` (`when` คือเงื่อนไขที่ระบบติ๊กแนะนำให้)
- **เพิ่มโรคประจำตัว** → `App.DISEASES` ใน `js/data.js`
- **เปลี่ยนสี** → ตัวแปรใน `:root` ของ `css/style.css`
- **เวลานัด** → `TIMES` ใน `js/view-appts.js` และ `js/view-plan.js`

แต่ละหน้าจอเขียนแบบเดียวกัน: `render()` คืน HTML, ปุ่มที่มี `data-act="ชื่อ"` เรียก `actions.ชื่อ()`, ช่องกรอกที่มี `data-f="ชื่อ"` เรียก `field()`
ข้อความที่มาจากผู้ใช้ต้องผ่าน `App.esc()` ทุกครั้งก่อนใส่ใน HTML

## นำขึ้นเว็บ (ฟรี) ด้วย GitHub Pages
1. สร้าง repository ใหม่ (เช่น `opd-paperless`) → อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. Settings › Pages › Deploy from branch › `main` / root
3. เปิด `https://<ชื่อผู้ใช้>.github.io/opd-paperless/`

**ทุกครั้งที่แก้ไฟล์แล้วอัปโหลดใหม่** ให้เปลี่ยนเลขใน `sw.js` (`opd-paperless-v1` → `v2`) เพื่อให้เครื่องที่ติดตั้งแอปไว้โหลดไฟล์ใหม่

## ระบบกลาง Google Sheets (ไม่บังคับ)
ใช้เมื่ออยากรวมข้อมูลจากหลายเครื่องไว้ที่เดียว
1. สร้าง Google Sheet ด้วยบัญชีของหน่วยงาน → **ส่วนขยาย › Apps Script** → วางโค้ดจาก `apps-script/Code.gs`
2. แก้ `const PASSWORD = 'CHANGE_ME';` เป็นรหัสทีม → บันทึก
3. **Deploy › การทำให้ใช้งานได้รายการใหม่ › เว็บแอป** (เรียกใช้ในฐานะ: ฉัน · ผู้มีสิทธิ์เข้าถึง: ทุกคน) → คัดลอก URL ที่ลงท้าย `/exec`
4. ในแอป หน้า **ตั้งค่า** ใส่ URL และรหัสทีม → กด “ส่งข้อมูลทั้งหมดขึ้นระบบกลาง”

ถ้าไม่มีเน็ต ข้อมูลจะรอในเครื่องและส่งให้อัตโนมัติเมื่อออนไลน์ (ดูจำนวน “รอส่ง” ที่มุมขวาบน)

## ข้อมูลและความเป็นส่วนตัว (PDPA)
- ข้อมูลเก็บใน **localStorage ของเบราว์เซอร์เครื่องนั้น** จะหายถ้าล้างข้อมูลเบราว์เซอร์หรือใช้โหมดไม่ระบุตัวตน → กด **ตั้งค่า › สำรองข้อมูล** ทุกสัปดาห์
- ใช้เครื่องของคลินิกที่มีรหัสผ่านล็อกหน้าจอ ไม่ใช้เครื่องสาธารณะ
- ไฟล์ CSV/JSON/PDF ที่ส่งออกมีข้อมูลสุขภาพ เก็บและส่งต่อตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล
- Google Sheet ที่ใช้เป็นระบบกลาง แชร์เฉพาะผู้เกี่ยวข้อง และไม่เปิดเผยรหัสทีม

## ข้อจำกัดที่ควรรู้
- **Thai CVD risk**: ตารางสีในคู่มือเป็นรูปภาพ แอปจึงให้กรอกปัจจัยเสี่ยงแล้ว**เลือกระดับความเสี่ยงที่อ่านจากตารางสีเอง**
- **FRAX**: คำนวณที่เว็บไซต์ FRAX แล้วนำผลร้อยละมาบันทึก
- ข้อมูลไม่ sync ระหว่างเครื่องแบบทันที (ระบบกลางเป็นการส่งขึ้นอย่างเดียว เพื่อรวบรวม/สำรองข้อมูล)
- เนื้อหาแบบประเมินอ้างอิง *คู่มือการคัดกรองและประเมินสุขภาพผู้สูงอายุ พ.ศ. 2564* กระทรวงสาธารณสุข ควรให้ทีมคลินิกตรวจทานข้อความและเกณฑ์ก่อนใช้งานจริง
